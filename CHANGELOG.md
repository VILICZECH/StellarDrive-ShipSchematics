# Changelog

## 1.0.3

- Extra material types on a survival blueprint no longer need a free chest slot. The extra amount is logged and still counts toward the build.
- The game's free-build cheat (F2 when developer tools are on) now places a schematic at once, the same way a creative world does. You do not need the Creative mode mod for that.
- In multiplayer each player places ships from their own collection. The host's list stays private. The host still builds the ship in the world.
- Vanilla rotors keep their heads when you save and place a schematic. Re-save older schematics that have a rotor so the head is stored.

## 1.0.2

- Save and place the whole machine: rotor and piston heads, docked ships, and the wires between them.
- The collection window scrolls, and you can search, sort, rename, delete, import and export `.schematic` files.
- Survival blueprints stay with the world save and can be recycled.
